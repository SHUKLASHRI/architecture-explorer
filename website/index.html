Engineered for Serious Python Codebases

A full suite of tools to understand, refactor, and untangle complex multi-package Python applications.

Interactive AST Topology

Instant parsing of your codebase using Python's native AST parser. Renders multi-tier dependencies (Presentation, Services, Persistence, Core) on an infinite hardware-accelerated canvas.

Circular Import Isolation

Runs Tarjan's Strongly Connected Components algorithm to detect circular imports before they cause runtime recursion crashes or module import failures.

Safe Multi-File AST Rename

Rename functions, classes, and methods across all project files simultaneously. Generates atomic dry-run diffs and verifies syntax before committing changes.

Dead Code Pruning

Analyzes repository-wide call graphs to identify dead functions and unreachable execution paths, helping you keep your codebase lean.

Embedded Monaco Studio

Edit code with VS Code's world-class Monaco editor right inside the workbench. Saving automatically triggers live re-analysis.

Integrated Terminal & Tests

Built-in bottom panel to execute test suites (pytest, unittest), inspect git diffs, and run python scripts directly from the IDE.

How It Works

Under the hood of the AST static analysis and refactoring engine.

1

AST Ingestion & Parsing

Irminsul IDE walks your codebase without executing code. Python's standard library ast parser extracts function signatures, class hierarchies, import statements, and call sites safely.

tree = ast.parse(source)
→ 24 modules indexed
→ 142 symbols resolved
2

Layer & Complexity Topology

The engine infers architectural roles (Presentation, Services, Persistence, Core) and computes cyclomatic complexity scores. Nodes are positioned automatically via Sugiyama or Force-Directed graph algorithms.

Layers: [API, Service, DB]
Complexity: Low (1) to High (12)
Layout: Hierarchical Sugiyama
3

Tarjan SCC Cycle Detection

Circular imports are isolated in linear O(V + E) time using Tarjan's Strongly Connected Components algorithm. Cyclic paths are immediately isolated into a dedicated HUD and highlighted in amber.

SCC detected: [auth, db, auth]
Severity: High Cycle
Recommendation: Extract interface
4

Atomic Multi-File Refactoring

Renaming a symbol updates every import, call site, and definition across the repository. A dry-run diff verifies syntax integrity before applying atomic writes to disk.

Files modified: 4
Live AST sync: Instant

Open Source Security & First-Time Launch Notes
  • Windows SmartScreen: Irminsul IDE binaries are 100% open-source and free of UPX packers. On first launch of a newly released version, Windows SmartScreen may show "Windows protected your PC". Simply click "More info" → "Run anyway" to launch.
  • macOS Gatekeeper: If macOS prompts that the developer cannot be verified, right-click IrminsulIDE.app in Applications and choose "Open" (or run xattr -cr /Applications/IrminsulIDE.app in Terminal).
  • Linux: Remember to grant execution permissions by running chmod +x IrminsulIDE-v1.0.0-x86_64.AppImage in your terminal before launching.
